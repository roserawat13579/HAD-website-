# Humla Association of the Deaf website

## Add your photos
Put photos in:
`assets/photos/`

The current classroom photo is:
`assets/photos/classroom-01.jpg`

## Change the logo
Replace:
`assets/logo.png`

Keep the same filename, and the website will use the new logo automatically.

## Add another gallery photo
Copy this block inside the `.gallery` section in `index.html`:

```html
<figure class="photo-card">
  <img src="assets/photos/your-photo.jpg" alt="Describe the photo">
  <figcaption>Your photo caption</figcaption>
</figure>
```

## Important
The Partner/Alliance section describes organisations as potential partners, not confirmed donors or formal partners.
